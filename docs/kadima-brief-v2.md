# קדימה — אפיון גרסה 2

## מה השתנה מגרסה 1
גרסה 1 הייתה אפיון + פרומפט. גרסה 2 מגיעה עם **קוד עובד**: הפרויקט בתיקייה הזו הוא אפליקציה רצה, לא הבטחה. המסמך הזה מתעד את מה שקיים ואת מה שנותר לבנות.

## המטרה בשורה אחת
כלי שעובד בשביל אדריכלית העיר — קולט חומר גלם בכל צורה, מארגן, מנסח ומדווח למנכ"ל, כשהמשתמשת רק מאשרת.

## מה בנוי (גרסה 1 עובדת)

### מסך זרימה (/)
תדריך בוקר מחושב (פעילות, מתאחרות, מוכנות, יעד קרוב), תיבת קליטה אוניברסלית שהופכת כל טקסט לרשומה בלחיצה אחת, ורשימת "דורש את תשומת ליבך" ממוינת לפי דחיפות.

### מסך טבלה (/table)
מסד הנתונים החי: כל עמודה ניתנת למיון בלחיצה על הכותרת, כל תא ניתן לעריכה inline עם שמירה אוטומטית, סינון לפי סטטוס, מינהל וחיפוש חופשי, הוספה ומחיקה של רשומות.

### מפת עבודה (/map)
רשומות מקובצות לפי מינהל, כל כרטיס עם שלבי ביניים שניתן לסמן כבוצעו והצגת "הצעד הבא".

### דוח למנכ"ל (/report)
WYSIWYG — הדוח מחושב מהנתונים בזמן אמת: הושלם, בתנועה, בסיכון, יוזמות. כפתור העתקה למייל.

### תשתית
- מקור נתונים מרכזי אחד (Zustand) — שינוי בכל מסך מתעדכן בכל המסכים.
- Supabase לשמירה קבועה, עם **מצב הדגמה** אוטומטי כשאין מפתחות — האפליקציה רצה מיד.
- סכמת SQL מלאה: tasks, task_steps, activity_log, departments, טריגר updated_at, RLS.
- RTL מלא, Noto Sans Hebrew, ללא אייקונים, מערכת צבעי סטטוס אחידה ב-tokens.

## מה נותר לבנות (לפי סדר, מתועד גם ב-CLAUDE.md)
1. מסך רשומה בודדת — כל השדות + ניהול שלבי ביניים.
2. Realtime — סנכרון בין מכשירים.
3. AI Ingestion — Claude API מזהה מהחומר הגולמי: שם, מינהל, איש קשר, תאריכים, צעד הבא.
4. Ghost Draft — ניסוח אוטומטי של מיילים וסיכומים.
5. Auth + מדיניות RLS אמיתית.
6. פריסה: GitHub + Vercel.
